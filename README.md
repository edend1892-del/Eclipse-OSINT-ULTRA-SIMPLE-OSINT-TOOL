# 🌑 Eclipse OSINT Framework
**Powered by the Red Dead Money Core**

Eclipse OSINT is an advanced, high-performance Reconnaissance and OSINT (Open-Source Intelligence) framework. 

This project was built from the ground up as a direct competitor and next-generation upgrade to the **Red-Demon** tool. While Red-Demon introduced basic OSINT concepts, Eclipse completely outclasses it by utilizing a fully Object-Oriented Programming (OOP) architecture, asynchronous multithreading for lightning-fast scraping, real-time API integrations, and a dynamic, customizable CLI built with Python's `rich` library.

## 🚀 Why Eclipse Over Red-Demon?
- **Speed:** Replaced slow, sequential requests with multithreaded asynchronous tracking.
- **Architecture:** Clean, modular OOP design making it highly scalable compared to monolithic scripts.
- **Visuals:** Ditch the basic terminal text. Eclipse features live progress bars, dynamic tables, and customizable UI colors.
- **Advanced Modules:** Features real Phone Number OSINT, Port Scanning, Minecraft Server data extraction, and Dark Web breach checking.
